# CMIS

**Cross-Chain Market Intelligence Service**

CMIS is the canonical project identity for this repository.

**ROBERTA — Verified On-Chain Intelligence** is the canonical public-facing product name for the user experience built above CMIS. CMIS remains the backend/repository identity. The former working product name **X1 Intelligence Service** is retired and must not be used as the current front-facing name.

The historical Liquidity Scout name describes the original prototype, but it no longer reflects the repository's primary role. CMIS is the deterministic intelligence backend used by chain-specific Scouts such as X1 Scout and Solana Scout. Those Scouts use CMIS to obtain verified, provenance-preserving information that is returned to Roberta for policy-aware coordination and user-facing synthesis.

The Python package namespace remains `liquidity_scout` temporarily for compatibility and will only be renamed under a separate tested migration milestone.

See `docs/CMIS_IDENTITY_MIGRATION.md` for the staged migration plan.
