Status: **cross-project product identity reference**

Effective: **2026-08-28**

The canonical public-facing product name above CMIS is:

# ROBERTA — Verified On-Chain Intelligence

CMIS remains the deterministic backend/repository identity. X1 Scout and Solana Scout remain chain-specialist component names beneath ROBERTA. The former working product name **X1 Intelligence Service** is retired and must not be used as the current public-facing name.

This naming decision changes branding only. It does not change the canonical authority path:

```text
User / transport
  -> Roberta
    -> Chain Scout
      -> CMIS
        -> Chain Provider / verified source
```

It does not change CMIS evidence, Proof Score, risk, identity, historical-data, capability-promotion, provider-trust, or execution semantics.

Technical identifiers such as `cmis`, `roberta-langgraph`, `liquidity_scout`, service-unit names, endpoints, and package namespaces are not renamed by this branding decision.

The repository-authoritative naming rules live in the Roberta repository at `docs/PRODUCT_IDENTITY.md`.
